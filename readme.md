*Nadprzestrzeń Filmowa - Archiwum Kinowej Przyszłości
Interaktywna strona internetowa poświęcona filmom i postaciom z gatunku Science-Fiction. Projekt powstał jako nowoczesne archiwum kinowe z podziałem na kategorie, wyszukiwarką oraz systemem zgłaszania własnych produkcji.

*Link do opublikowanej strony na GitHub Pages:
[Otwórz stronę na GitHub Pages](https://gabrielw45.github.io/nadprzestrzen-filmowa/)

*Wykorzystane Technologie
-HTML5 – struktura dokumentu i semantyczne znaczniki
-CSS3 – stylowanie, Flexbox, CSS Grid, zmienne CSS oraz wsparcie dla jasnego i ciemnego motywu
-JavaScript – interaktywność, dynamiczne filtrowanie, obsługa LocalStorage i walidacja formularzy
-Git / GitHub Pages – wersjonowanie kodu i publikacja projektu

*Główne Funkcje
-Przeglądanie katalogu filmów SF z podziałem na podgatunki (Cyberpunk, Space Opera, Hard Sci-Fi, First Contact).
-Interaktywna wyszukiwarka filmów po tytule w czasie rzeczywistym.
-Przełącznik motywu (ciemny/jasny) z pełnym dostosowaniem kontrastu i elementów interfejsu.
-Sekcja kultowych postaci oraz nadchodzących premier.
-Interaktywny modal umożliwiający użytkownikowi zgłoszenie własnego filmu z walidacją 4-cyfrowego roku produkcji.
-Trwałość danych dzięki wykorzystaniu pamięci przeglądarki (LocalStorage).
-Rozwijane sekcje typu FAQ oraz formularz newslettera.
